# seller-marketplace

Seller Marketplace는 판매자와 구매자를 위한 이커머스 플랫폼입니다. 사용자는 상품을 등록하고, 관리하며, 구매할 수 있습니다.
프로젝트는 Django를 기반으로 개발되었습니다.

## 주요 기능

- **사용자 관리 (Accounts):** 회원가입, 로그인, 로그아웃, 회원 정보 수정, 프로필 이미지 변경, 팔로우/언팔로우
- **상품 관리 (Products):** 상품 등록, 수정, 삭제, 목록 조회, 상세 조회, 검색, 필터링, 정렬, 카테고리 관리
- **주문 및 결제 (Orders):**
    - **장바구니:** 상품을 장바구니에 담고, 수량을 조절하며, 주문할 상품을 선택할 수 있습니다.
    - **주문 생성:** 장바구니에 담긴 상품 또는 개별 상품을 즉시 구매하여 주문을 생성합니다.
    - **결제 처리:** Portone(아임포트) 결제 연동을 통해 안전하고 간편하게 결제를 진행합니다.
    - **주문 내역 조회:** 사용자는 자신의 주문 내역과 배송 상태를 확인할 수 있습니다.
    - **구매 이력 조회:** 판매자는 자신의 상품에 대한 판매 내역을 확인할 수 있습니다.
- **리뷰 (Reviews):** 구매한 상품에 대한 리뷰를 작성, 수정, 삭제하고, 별점을 부여할 수 있습니다. 다른 사용자들의 리뷰를 조회하고 필터링할 수 있습니다.
- **알림:** 새 상품 등록 시 팔로워에게 알림을 보내는 기능이 있습니다.

## Orders App 기능 상세

### 1. 주문/결제 페이지 (`orders/orders.html`)
- **기능:** 장바구니에 담긴 상품 목록을 확인하고, 배송지 정보를 입력하여 최종 결제를 진행하는 페이지입니다.
- **주요 로직:**
    - `GET` 요청 시: 현재 로그인된 사용자의 장바구니 정보를 불러와 주문할 상품 목록과 사용자 정보를 함께 렌더링합니다.
    - Portone(아임포트) API와 연동하여 결제 기능을 제공합니다. (`storeId`, `channelKey` 등 환경 변수 사용)
    - 배송지 정보를 입력하고 관리할 수 있습니다. (AJAX를 통해 비동기적으로 배송지 정보 업데이트 예정)
- **URL:** `/orders/`

### 2. 장바구니 상품 삭제
- **기능:** 주문/결제 페이지에서 특정 상품을 장바구니에서 삭제합니다.
- **주요 로직:**
    - `pk`를 인자로 받아 해당 `Cart` 객체를 삭제하고, 다시 주문/결제 페이지로 리다이렉트합니다.
- **URL:** `/orders/cart/<int:pk>/delete/`

### 3. 주문 완료 페이지 (`orders/order_done.html`)
- **기능:** 결제가 성공적으로 완료된 후, 사용자에게 주문 완료 메시지를 보여주는 페이지입니다.
- **주요 로직:**
    - `POST` 요청 (결제 완료 후 리다이렉션) 시, 주문 완료 템플릿을 렌더링합니다.
    - 향후 주문 상세 내역을 보여주는 기능 추가 예정입니다.
- **URL:** `/orders/done/`

## 페이지별 기능 (Products App 중심)

### 홈화면
- 서비스 접속 초기 화면으로, 상단에 네비바와 카테고리바가 있으며 쇼핑몰의 현황을 한눈에 보여줍니다.
![홈페이지](https://github.com/heize-lee/seller-marketplace/assets/130022109/670b7d5e-6981-45a2-b72f-07c593e21ac1)

### 상품 리스트
- 등록된 상품들을 상단 카테고리바를 이용하여 카테고리별로 분류해서 볼 수 있습니다.
- 화면 좌측 필터를 통해 상품명으로 상품을 검색할 수 있고, 가격 범위를 설정하여 범위 안에 있는 상품만 필터링할 수 있습니다.
- 우측 정렬 옵션을 통해 최신순, 가격 낮은순, 가격 높은순, 별점 높은순, 별점 낮은순으로 상품을 정렬할 수 있습니다.
![상품리스트](https://github.com/heize-lee/seller-marketplace/assets/130022109/3eb0c90f-d793-4103-a4b3-fae157377ab1)

- URL 복사 버튼을 누르면 현재 페이지의 URL이 복사됩니다.
- 상품 정보 더보기 버튼을 통해 상품 상세 정보를 간편하게 볼 수 있습니다.
